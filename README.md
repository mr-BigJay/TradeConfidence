# TradeConfidence

ابزار و چک‌لیست‌های سبک برای تصمیم‌گیری سریع در معاملات فیوچرز کریپتو.

## 🖥️ اجرا روی ویندوز ۱۱ (بدون نصب)

هیچ Python، Node یا نصبی لازم نیست. کل ابزار یک فایل HTML مستقل است که در Edge/Chrome اجرا می‌شود.

### روش ۱ — سریع‌ترین راه

1. این ریپو را دانلود کن (سبز رنگ **Code → Download ZIP** در گیت‌هاب).
2. ZIP را از حالت فشرده خارج کن (کلیک راست → *Extract All*).
3. وارد پوشه‌ی `app` شو.
4. روی فایل **`index.html`** دابل‌کلیک کن — در مرورگر پیش‌فرض ویندوز باز می‌شود.

### روش ۲ — با فایل اجرایی

داخل پوشه‌ی `app` روی فایل **`Run.bat`** دابل‌کلیک کن. همین.

> 💡 اگر ویندوز هشدار «Windows protected your PC» داد، روی **More info → Run anyway** بزن. Run.bat فقط یک خط دستور دارد که فایل HTML را باز می‌کند.

### روش ۳ — با گیت (برای بروزرسانی راحت)

```powershell
git clone https://github.com/mr-BigJay/TradeConfidence.git
cd TradeConfidence\app
start index.html
```

## 📁 محتوای ریپو

- [`app/index.html`](./app/index.html) — اپ تک‌فایلی چک‌لیست ۳۰ ثانیه‌ای (محاسبه خودکار امتیاز لانگ/شورت)
- [`app/Run.bat`](./app/Run.bat) — اجرای سریع در ویندوز
- [`checklists/30s-long-short-checklist.md`](./checklists/30s-long-short-checklist.md) — نسخه‌ی متنی چک‌لیست برای مطالعه/چاپ

## ✨ چه کاری انجام می‌دهد؟

مقدار ۵ شاخص را وارد می‌کنی و ابزار به‌صورت خودکار:

1. برای هر شاخص یک برچسب **لانگ / شورت / خنثی** نشان می‌دهد.
2. امتیاز نهایی **Long Score** و **Short Score** (از ۵) را حساب می‌کند.
3. تصمیم پیشنهادی (LONG / SHORT / NO TRADE) و سطح اطمینان را نمایش می‌دهد.
4. یک خروجی متنی آماده برای کپی در ژورنال معاملاتی می‌سازد.

پنج شاخص: **Funding Rate**، **Open Interest (OI)**، **CVD**، **RSI(14)**، **Long/Short Ratio**.

## 🔒 حریم خصوصی

هیچ داده‌ای به هیچ سروری فرستاده نمی‌شود. کل محاسبات داخل مرورگر خودت اجرا می‌شود و حتی می‌توانی سیستم را از اینترنت قطع کنی.
